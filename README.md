# SQL Practice Repository 📊

This repository contains my SQL practice work using **MySQL Workbench**.
It includes database creation, table operations, data insertion, and analytical SQL queries.

## 🛠️ Tool Used

* MySQL Workbench

## 📚 Topics Covered

### Database & Table Management

* Creating databases
* Selecting databases using `USE`
* Viewing databases and tables
* Creating tables using `CREATE TABLE`
* Understanding table structure using `DESCRIBE`

### Data Manipulation

* Inserting records using `INSERT INTO`
* Retrieving data using `SELECT`
* Working with employee and sales datasets

### Aggregate Functions

Practiced important SQL aggregate functions:

* `COUNT()` → Counting records
* `SUM()` → Calculating total values
* `AVG()` → Finding average values
* `ROUND()` → Formatting numerical results

### Grouping & Filtering

* Using `GROUP BY` for category-wise analysis
* Using `HAVING` to filter grouped data

Examples:

* Average age by department
* Total salary by department
* Employee count by city
* Departments with average salary greater than a specific value

### Business Analysis Queries

Performed analysis on:

**Employee Dataset**

* Average employee age
* Department-wise salary analysis
* Employee distribution by city
* Department salary insights

**Sales Dataset**

* Product-wise revenue calculation
* Revenue analysis using:

  ```
  sell_price × quantity
  ```
